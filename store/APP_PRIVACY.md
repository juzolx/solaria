# App Store Connect: App Privacy answers (DRAFT)

**This version (online off):** "Data Not Collected". No tracking. No third-party SDKs that collect data.

**When online features are switched on, update to:**

| Data type | Collected | Linked to the user | Used for tracking | Purpose |
|---|---|---|---|---|
| User ID (anonymous account id) | Yes | Yes | No | App Functionality |
| Other User Content (online name, guild name) | Yes | Yes | No | App Functionality |
| Gameplay Content (floors, runs, cloud backups) | Yes | Yes | No | App Functionality |
| Purchase History | No (Apple handles it) | | | |

- Tracking: **No** (no ads, no data brokers, no cross-app tracking).
- Account deletion: in the game (Menu > Cloud backup > Delete my online account). Apple requires this for any app that creates accounts.
- Privacy Policy URL: host store/PRIVACY_POLICY.md somewhere public (a free GitHub Pages site works) and paste the link.
