# Consumable icons

- potion, greater, might, iron, fortune: "cc0 potion icons" (Dungeon Crawl Stone Soup set), collected by AntumDeluge. CC0. https://opengameart.org/content/cc0-potion-icons
- luck, return (tinted), box, hunt, key, tome: Dungeon Crawl Stone Soup tiles ("Dungeon Crawl 32x32 tiles"). CC0. https://opengameart.org/content/dungeon-crawl-32x32-tiles
- backpack: drawn for Solaria.

- egg.png: drawn for Solaria (CC0).

2.1: tools/bake_art.gd mapped these files to the Solaria palette (art_style.gd, art/palette.gpl), made every pixel solid and gave them one dark outline. The originals are in git history.
