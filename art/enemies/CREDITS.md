# Monster, boss, Calamity and pet art

Dungeon Crawl Stone Soup 32x32 tiles, CC0 (https://opengameart.org/content/dungeon-crawl-32x32-tiles), by the DCSS artists (https://github.com/crawl/tiles/blob/master/ARTISTS.md).
Built by tools/dcss_monsters.py: baked shadows removed, some recolored, rim light, 2x upscale, dark outline.

0.13+ myth monsters (hobyah, jack_in_irons, ankou, bog_body, ningyo, afanc, gullinbursti, div, mare, baku): Dungeon Crawl Stone Soup tiles (CC0), 2x by tools/make_myths.gd.

2.1: tools/bake_art.gd mapped these files to the Solaria palette (art_style.gd, art/palette.gpl), made every pixel solid and gave them one dark outline one art pixel wide, on one 2x grid (68x68 files, two-tile giants 68x132). The originals are in git history.
